# React To-Do List Application

## 📌 Project Overview

This project is developed as part of **Task 3 – Front-End Framework Basics** during my internship.

The objective of this task is to learn the fundamentals of a front-end framework and build a small interactive application using **React.js**.

A **To-Do List Application** was created that allows users to add, edit, and delete tasks. The project demonstrates the use of React components, state management, event handling, and dynamic rendering.

---

## 🎯 Objectives

* Learn the basics of React.js.
* Understand React components.
* Work with state and props.
* Handle user events.
* Dynamically display data.
* Implement Add, Edit, and Delete functionality.
* Build an interactive front-end application.
* Understand the basic workflow of a modern front-end framework.

## ✨ Features

### ➕ Add Tasks

Users can enter a task and add it to the To-Do list.

### ✏️ Edit Tasks

Existing tasks can be edited and updated.

### 🗑️ Delete Tasks

Users can remove tasks from the list when they are no longer required.

### 🔄 Dynamic UI

The task list updates automatically when tasks are added, edited, or deleted.

### 📱 Responsive Interface

The application is designed to provide a simple and user-friendly experience across different screen sizes.

---

## ⚛️ React Concepts Used

This project demonstrates several fundamental React concepts.

### Components

The application is divided into reusable React components to organize the user interface and functionality.

### State

React state is used to store and manage the current list of tasks.

### Event Handling

Events such as button clicks and form submissions are handled using React event handlers.

### JSX

JSX is used to write the user interface using a syntax that combines JavaScript and HTML-like elements.

### Dynamic Rendering

The task list is dynamically rendered based on the current application state.

---

## 🔄 Application Flow

```text
User enters a task
        ↓
     Add Task
        ↓
Task stored in React State
        ↓
Task displayed on screen
        ↓
 ┌──────┴──────┐
 ↓             ↓
Edit          Delete
 ↓             ↓
Update       Remove
 ↓             ↓
React State updates
        ↓
UI automatically updates
```

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd todo-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Vite will provide a local development URL in the terminal.

Open that URL in your web browser to use the application.
